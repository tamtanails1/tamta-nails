საიტის გაშვება
საიტი შედგება HTML, CSS და JavaScript ფაილებისგან. npm install და build არ სჭირდება.
ადგილობრივად სანახავად გახსენი index.html ბრაუზერში ან გამოიყენე ადგილობრივი HTTP სერვერი.

GitHub-ზე ატვირთვა და გამოქვეყნება
1. შექმენი GitHub რეპოზიტორია ან გახსენი არსებული.
2. ამ საქაღალდის შიგთავსი ატვირთე რეპოზიტორიის ზედა დონეზე:
   index.html
   service.html
   tamtasnails.css
   tamtasnails.js
   img/ — ყველა გამოსახულებით
   video/nails-work.mp4
   .nojekyll
   .gitattributes
   README.txt
3. index.html უნდა ჩანდეს პირდაპირ რეპოზიტორიის ზედა დონეზე.
   ნუ ატვირთავ მხოლოდ ZIP-ს: GitHub Pages არქივს თავისით არ შლის.
4. შეინახე ცვლილებები Commit changes-ით.
5. გახსენი Settings → Pages.
6. Source-ში აირჩიე Deploy from a branch.
7. Branch-ში აირჩიე main (ან ის branch, სადაც ფაილები ატვირთე),
   საქაღალდედ აირჩიე /(root) და დააჭირე Save-ს.
8. გამოქვეყნების დასრულების შემდეგ საიტის მისამართს იმავე Pages გვერდზე ნახავ.
